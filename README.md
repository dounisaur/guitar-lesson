# Guitar Lesson Skill

Daily acoustic guitar practice routine for Claude Code.

Run with `/guitar-lesson` in Claude Code.

## Features

- **Optional warm-ups** (1-15 minutes): chord transitions, fingerpicking, barre chords, strumming, scales, or full mix
- **Song learning**: curated list matched to intermediate acoustic level
- **Multiple resources**: Ultimate Guitar tabs, YouTube tutorials, chord diagrams
- **Flexible feedback**: request alternative sources or different songs

## Your Profile

- **Level**: Intermediate (can play Alice in Chains Nutshell, The Cure Lovesong, Smells Like Teen Spirit solo)
- **Equipment**: Full-sized Fender acoustic
- **Preferences**: Acoustic tutorials, Ultimate Guitar tabs
